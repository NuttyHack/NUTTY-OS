---
name: NUTTY blank-slate principle
description: Product rule for truthful first-run behavior and demo data.
---

NUTTY's default experience must be a blank slate. It must not invent identity, schedule, goals, health signals, readiness, nutrition, finances, progress, or achievements. Any demo data used during development must be explicitly opt-in and clearly separated from the default account experience.

**Why:** The product vision makes "never invent the user" a primary trust requirement.

**How to apply:** When adding a personal module, render an honest empty or "not enough information yet" state until real user input or an authorized integration supplies data.
